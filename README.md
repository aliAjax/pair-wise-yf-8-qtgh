# 放映线路编排台

一个纯前端本地应用（无依赖、单页面），由「胶片分镜条核对台」扩展而来，用于把多卷胶片排进放映线路、登记片盒、核对每卷片段规格。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。数据通过 `localStorage` 本地保存，刷新页面后保留。

## 预置资源

- **三条线路**：一号主线厅（3 卷）、二号艺术厅（2 卷）、三号流动线（2 卷），件数即每线路未结束卷上限。
- **五种片盒**：标准片盒、加长大盒、短卷小盒、预告贴片盒、备用空片夹，各有总库存，可在片盒面板调整（不得低于当前占用）。
- **每卷片段规格**：单卷片段数上限与总时长上限，改动会重算全部未结束卷。

## 卷的生命周期

- **开卷登记**：选择题名、线路并登记每种片盒数量。
  - 片盒被其他**放映中**卷占用导致可用量不足，或线路件数已达上限 → **整卷拒绝**，不入列、现有排序不变。
  - 需求量超过片盒总库存（缺盒）→ 允许登记但进入 **缺盒冻结**：不持片盒、但占线路件位。
- **恢复**：补足库存或其他卷停映/撤销释放片盒后，按登记顺序自动恢复，也可手动点「恢复放映」。
- **停映 / 撤销**：释放片盒与线路件位，卷进入存档（只读，可删除），并触发缺盒卷自动恢复。

## 规格重算

调整片段规格后对所有未结束卷（放映中 + 缺盒冻结）重算；只要任一卷超限，**整组退回**，新规格不生效并给出超限明细。录入片段导致当前卷超限同样拒绝，排序不变。

## 代码结构

- `Store`：存档同步（localStorage 读写、旧版单卷数据迁移）。
- `Scheduler`：占用判断、线路件数、规格判定，全部为纯函数。
- UI 层（渲染 + 事件）：只负责页面事件与渲染，经统一 `commit()` 入口调用前两层并重绘。
