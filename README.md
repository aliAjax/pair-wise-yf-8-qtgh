# 放映线路编排台

一个纯前端本地应用，在原「胶片分镜条核对台」基础上扩展为多卷次的放映线路调度台。直接打开 `index.html` 即可使用，刷新后数据保留在 localStorage 中，无新增依赖、无额外页面。

## 预置资源

- **三条放映线路**：一号主线（2 卷）、二号副线（2 卷）、三号机动线（1 卷），件数上限即该线路同时允许的放映中卷数。
- **五种片盒**：35mm 标准盒（4）、16mm 教学盒（5）、8mm 家用盒（3）、预告片盒（2）、备用备份盒（2）。
- **每卷片段规格**：每卷片段数、单段时长、每卷总时长三个上限，可在右侧修改。

## 调度规则

- **开卷**：填写卷名、选择线路、登记五种片盒数量。片盒被其他未结束卷占用（空闲为 0）或数量不足、或线路件数超限时，**整卷拒绝**，不写入任何状态，现有卷次排序与占用保持不变。
- **缺盒卷**：片盒尚未到齐时可用「缺盒登记（冻结）」，冻结卷登记在册但**不占用**线路件数与片盒；到齐后点「恢复」，恢复时按开卷同样的规则重新校验，不满足则继续保持冻结，排序不变。
- **释放**：未结束卷可「停映」（正常结束）或「撤销」（取消），释放其线路件数与全部片盒。
- **片段规格**：修改后重算全部未结束卷（放映中 + 缺盒冻结），任一超限则**整组退回**，输入还原为旧规格，状态不变。加入片段同样按当前规格做单卷事务校验，超限拒绝、顺序不变。
- 片段拖拽排序仅对未结束卷开放；停映/撤销卷的顺序锁定。

## 代码分层（app.js）

1. **存档层（Archive）**：预置数据、旧版单卷存档迁移、localStorage 读写，仅在事务成功后保存。
2. **占用层（Occupancy）**：线路件数、片盒占用、规格违规的纯查询与整卷事务判定，不触碰 DOM。
3. **页面层**：渲染与事件监听，只消费上面两层；事件处理器不含调度规则。
